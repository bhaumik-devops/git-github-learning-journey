# Day-06 Practical Tasks

This folder contains the practical records for the Git commands practiced during Day-06.

## Completed Practical Tasks

### 1. git diff

- Inspected unstaged changes.
- Verified added and modified lines using Git diff.

### 2. git diff --staged

- Inspected changes that were already staged.
- Used it to review changes before committing.

### 3. git restore --staged

- Removed a file from the staging area.
- Verified that the working-directory changes were preserved.

### 4. git show

- Inspected a specific commit.
- Reviewed commit hash, author, date, commit message, changed files, and actual changes.

### 5. git show --stat

- Inspected a commit summary.
- Reviewed changed files, insertions, and deletions.

### 6. git restore

- Created a temporary unstaged modification.
- Used `git diff` to verify the modification.
- Used `git restore` to discard the unstaged change.
- Verified that the working tree returned to its previous state.
