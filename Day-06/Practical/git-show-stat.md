# git show --stat Practical

## Command

git show --stat 629d7ed

## Result

The command displayed a summary of commit `629d7ed`.

- File changed: README.md
- Files changed: 1
- Insertions: 6
- Deletions: 1

## Learning

`git show --stat` provides a summary of the files and line changes introduced by a commit without displaying the complete line-by-line diff.
